# Orbia v0.3 β
「誰がいても、誰が休んでも、仕事がつながる」を目的とした業務標準化・管理システムのGitHub試作版です。

## v0.3 β の主な機能
### 共通タブ
- ホーム
- カレンダー
- TODOリスト
- 業務
- 引継ぎ
- 照会・調査
- 設定
- 使い方

### ホーム
- 経営企画係長 / 算定病歴係長の役割選択
- 両方の予定・TODOを同時表示
- 役割別ダッシュボード

### カレンダー
- 予定追加
- 予定変更
- 予定削除
- 担当別フィルタ
- TODO期限を自動表示
- 予定単位のメール設定

### 経営企画係長
- 院内報告
- 院外報告
- 委員会
- 会議
- 年次業務
- その他業務
- 各業務から「データ取込 → 資料作成 → プレビュー → 登録」
- エラー時の再実行 / デスクトップ作成 / あとで登録
- 病院収益・統計ダッシュボード（現在はダミーデータ）

### 算定病歴係長
- 報告
- 委員会
- 検証
- 算定チェック
- 診療報酬改定 / 施設基準届出
- 施設基準検証結果登録のUI
- 要注意 / 上位基準取得可能性のサンプル判定
- 届出予定のカレンダー登録

### 引継ぎ
- 緊急引継ぎ
- 現在進捗
- 業務マニュアル
- 常時最新の引継書

### 照会・調査
- 疑問・経緯
- 照会先 / 回答者
- 回答
- 今後の取扱い
- 関連業務
- キーワード検索
- 0件なら「まだ記録がない」と表示

## 今アップロード済みのv0.1から更新する方法
ZIPを解凍し、**中身をリポジトリのルートへ上書きアップロード**してください。

主に置き換えるファイル:
- `index.html`
- `styles.css`
- `app.js`
- `assets/`
- `README.md`

GitHub Pagesの設定がすでに `main / (root)` なら、Pages設定をやり直す必要はありません。

## 重要
この版はGitHub UI試作用です。
以下を登録しないでください。
- 患者氏名 / 患者ID
- 職員個人情報
- 院内機密資料
- 実際の収益データ
- SharePoint内部URL
- APIキー / パスワード / 認証情報
